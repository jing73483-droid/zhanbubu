# Moonlit Tarot Companion · 月光塔罗陪伴

面向情绪与关系困扰场景的移动优先产品原型。以塔罗作为表达入口，将用户输入组织为「共情回应 → 象征性解读 → 温和行动建议」的体验。

**当前版本为交互演示**，使用本地模板生成示例解读，未接入真实大模型服务。包含中文与泰语界面，主要用于展示需求分析、产品取舍及交互设计。

[产品需求文档](PRD/README.md) · [市场研究](MRD.md) · [商业需求](BRD.md) · [设计规范](DESIGN.md)

## 产品背景与用户问题

研究材料来自 TikTok 泰语占卜内容下的评论，涉及关系困扰、家庭责任、孤独和疲惫等表达。产品尝试提供低门槛的情绪表达与自我梳理体验。

这些评论属于探索性样本，不能代表整体泰语市场，也不构成用户付费意愿已获验证的证据。证据与适用范围见 [data-context.md](data-context.md)。

## 产品设计与关键取舍

- **聚焦单次体验**：先选择状态、抽牌并输入问题，再进入三段式解读结果页。
- **缩小 MVP**：暂不引入复杂账号、多轮咨询或真实支付，优先检验表达与解读体验。
- **明确验证方式**：PRD 规划保存、追问、等待名单和付费意愿等行为指标；这些是待实施的验证计划，并非已有业务成果。
- **保留产品边界**：塔罗文本用于象征性反思，不承诺预测准确性，不替代医疗、法律或财务建议。

## 体验流程

1. 打开演示，按需切换中文 / 泰语。
2. 选择当前情绪状态，抽取牌面。
3. 输入一段示例问题并提交。
4. 查看共情、解读与下一步建议；通过返回按钮重新体验。

内容保存在当前浏览器中，不应输入敏感或真实隐私信息。结果链接依赖本机 localStorage，复制给别人不会同步原有解读。

## 本地运行

使用 Node.js 20 和 npm。

```bash
cd moonlit-tarot-companion
npm ci
npm run dev
```

打开 http://localhost:3000。当前演示不需要 API Key；源码中的 SDK 依赖不代表对应云服务已接通。

## 构建与部署

```bash
cd moonlit-tarot-companion
npm run build
```

生成静态文件到 `out/`。部署到本仓库的 GitHub Pages 时使用 `GITHUB_PAGES=true npm run build`，自动添加 `/zhanbubu` 路径前缀。

仓库包含 Pages 工作流，推送 main 后构建并尝试部署。首次部署需在仓库 Settings → Pages 选择 GitHub Actions。实际可访问链接以成功部署结果为准。

若后续接入真实模型，需另行部署服务端接口管理密钥、限流与风险处理，GitHub Pages 仅托管静态前端。
